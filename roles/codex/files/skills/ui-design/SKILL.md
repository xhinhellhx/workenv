---
name: ui-design
description: Design or refine a web application's interface, responsive layout, navigation, and interaction states.
---

Identify the user, primary task, and existing design conventions. Preserve shared components, tokens, and established navigation when they fit the task. Establish information hierarchy and layout around the main action and the feedback users need.

Design the states that affect the workflow, including loading, empty, validation, and recovery. Keep copy actionable and use meaningful controls. Account for narrow layouts, zoom, keyboard navigation, visible focus, semantic labeling, and contrast. [WCAG 2.2](https://www.w3.org/TR/WCAG22/)

When implementing or reviewing, use the project's normal entry points and verify the affected workflow at representative viewport widths. Check keyboard order and focus transfer for overlays or route changes. For a design-only request, describe the screens, transitions, and component states needed to implement it.
